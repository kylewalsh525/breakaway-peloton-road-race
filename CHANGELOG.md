# Changelog

## 0.9.0 — Source delivery, 2026-09-30

Initial executable browser/server release: four original arcade courses, power-based racing, AI/combat/resources, voice-command routing, career records, authenticated multiplayer/phone pairing, capability-isolated Android source and deployment/test tooling.

Delivery verification includes 141 Node tests, 45 rendered-browser checks and a real 32-rider localhost load run. Regression fixes include confidence filtering, duplicate command suppression, small-landscape layout, contact spacing, stale power, reload input-sequence recovery, stable race-result identity, torn-journal recovery and a bounded post-finish waiting window.

Android APK assembly and physical Peloton/microphone validation have not been run. See docs/TEST_REPORT.md and docs/RELEASE_CHECKLIST.md before installing or publishing compatibility claims.
